**Public and self-contained.** Commit messages, code comments, and docs are public: a reader has only the repo, not your journal or session log. Never reference either, and never lean on context the repo cannot show: an audit, a conversation, a ticket, a session finding, internal jargon or codenames, a measurement taken outside the repo. Describe the change on its own terms. In a commit message, personal content is licensed only by the repo's own history; otherwise a name is written "the user", never the name, while a path or identifier stays exact.

**Synthetic fixtures.** Test fixtures, examples, and sample data are written from scratch, never adapted from real files, project names, work topics, or any other private content, even "neutralized". Generic names only: `foo`, `acme`, `example.com`. A real name that survived into sample data is a defect even when the code works.
